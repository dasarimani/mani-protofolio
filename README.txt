# Dasari SB Manikanta — Kuku FM AI Architect Fellowship Portfolio

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `manikanta-portfolio`.
2. Upload `index.html` and `Manikanta_Resume.pdf` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch → `main` → `/ (root)` → Save.
5. After GitHub publishes it, your website URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/manikanta-portfolio/`

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username. Do not share a guessed URL as a live site.
